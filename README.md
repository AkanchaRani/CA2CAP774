## 🚀 Practical Programs

### 1. Bill Calculator (`Bill.html`)

A JavaScript program that calculates the final payable bill amount after applying a discount.

**Discount Conditions:**
- Bill amount greater than ₹2000: 15% discount.
- Bill amount ₹2000 or below: 5% discount.

**Concepts Used:**
- JavaScript functions
- Variables
- Conditional statements (`if-else`)
- DOM manipulation
- Arithmetic operators

### 2. Duplicate Element Finder (`Duplicate.html`)

A JavaScript program that identifies duplicate elements in an array and displays the unique elements.

**Features:**
- Displays the original array.
- Removes duplicate elements.
- Displays the unique array.
- Counts the occurrences of each duplicate.
- Displays the indexes of duplicate elements.

**Concepts Used:**
- Arrays
- Nested loops
- Conditional statements
- Variables
- Array traversal

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `Bill.html` or `Duplicate.html`.
4. Run the HTML file in a web browser.
5. View the output.
